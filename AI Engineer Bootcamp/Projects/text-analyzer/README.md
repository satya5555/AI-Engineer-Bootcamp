# Text Analyzer

A simple NLP application built using Hugging Face Transformers as part of the AI Engineer Bootcamp.

## Features

- Sentiment Analysis
- Emotion Classification
- Confidence Scores
- Multiple Hugging Face Models

## Technologies

- Python
- Transformers
- PyTorch
- Hugging Face

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Models Used

- distilbert-base-uncased-finetuned-sst-2-english
- j-hartmann/emotion-english-distilroberta-base

## Learning Objectives

- Hugging Face Models
- NLP Pipelines
- Sentiment Analysis
- Emotion Classification
